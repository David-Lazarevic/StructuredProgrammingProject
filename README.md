# The Mindful Kitchen 🍳

A text-based cooking puzzle console application developed in Java for the Structured Programming course (1st Semester).

## 👤 Author
- **Author:** David Lazarevic
- **Course:** Structured Programming (1st Semester)

---

## 📖 Project Description
*The Mindful Kitchen* is a text-based puzzle game played in the console. The player takes on the role of a chef who must serve **2 random customers** per shift out of a pool of **6 unique customer types**.

Each customer announces a hint about their preferences upon arrival (e.g., preference for spicy food, vegetarian dishes, or low-carb options). Using a provided **cookbook** and a randomly selected inventory of ingredients, the player must:
1. Select the correct ingredients based on customer hints.
2. Choose the right preparation method (e.g., boiled vs. baked).
3. Set the correct cooking time.

At the end of the dish preparation, the customer provides feedback and a final rating score.
